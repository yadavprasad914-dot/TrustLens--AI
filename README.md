# TrustLens-AI

TrustLens-AI is an AI-powered file analysis and risk detection system designed to analyze files, identify potential risks, and generate detailed reports.

## Features

- File analysis
- Risk detection
- AI-powered analysis
- Automated PDF report generation
- Simple and user-friendly interface
- Python-based implementation

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Machine Learning
- PDF Generation
